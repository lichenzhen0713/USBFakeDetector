# USB 扩容盘检测工具

> 检测 U 盘 / 存储卡 / 移动硬盘是否**虚标容量**（扩容盘），并给出**实际可用容量**。  
> Detect fake-capacity USB drives on Windows — real capacity, safe mode, high-DPI UI.  
> Windows 10/11 · 图形界面 · 单文件 EXE · 需要管理员权限

## 快速开始

### 直接运行（推荐）

1. 下载 [UsbFakeDriveDetector.exe](https://github.com/lichenzhen0713/USBFakeDetector/raw/main/dist/UsbFakeDriveDetector.exe)
2. 双击运行，在 UAC 提示中选择“是”
3. 插入 U 盘，点击 **刷新**
4. 选中 U 盘 → 勾选确认 → 选择检测方式 → **开始检测**

> 国内访问 GitHub 较慢时，可使用 Gitee 镜像：  
> https://gitee.com/lichenzhen0713/USBFakeDetector  
> Gitee 直接下载：[UsbFakeDriveDetector.exe](https://gitee.com/lichenzhen0713/USBFakeDetector/raw/main/dist/UsbFakeDriveDetector.exe)

> EXE 未签名，Windows 可能提示“未知发布者”，选择“仍要运行”即可；也可以按下方方法自行编译。

### 从源码编译

需要 Windows 自带的 .NET Framework 4.x（Win10/11 默认包含）：

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

生成 `bin\UsbFakeDriveDetector.exe` 与 `bin\selftest.exe`。

## 它能做什么

- 自动列出 USB 磁盘，显示盘符、卷标、文件系统、标称容量、型号、序列号。
- **快速扫描**：全盘抽样 + 别名探测，1–3 分钟先给出初步结论。
- **完整校验**：写满标称容量并逐块读回，最可靠；扩容盘会在真实容量附近**自动提前终止**。
- **安全模式（保留文件）**：只写文件系统标记为空闲的区域，通常 **1–3 秒**完成，不创建/删除文件。
- 显示 **实际可用容量**（如标称 268 GB 的假盘实测约 8.31 GB）。
- 自动生成中文检测报告，保存到 `文档\U盘容量检测报告\`。
- 高 DPI 自适应界面，窗口可自由缩放。

## 三种检测方式

| 方式 | 写入量 | 耗时 | 适合场景 |
| --- | --- | --- | --- |
| **快速扫描** | 全盘采样，几百 KB | 约 1–3 分钟 | 先快速判断；抽样检查，可能漏检 |
| **完整校验** | 写满标称容量 | 容量 ÷ 速度 | 最可靠；假盘会提前终止，不会真写满 268 GB |
| **安全模式（保留文件）** | 只写空闲区约 0.5 MB | 通常 1–3 秒 | 不想清空 U 盘；抽样检查，回绕型假盘可能漏检 |

> 安全模式需要卷已格式化、至少有 32 MB 空闲空间；检测时该卷会临时卸载约 1 秒，结束后自动恢复。

## 检测结果怎么看

| 结论 | 含义 | 建议 |
| --- | --- | --- |
| ✔ 正常：未发现扩容迹象 | 本次检测没有发现地址回绕或丢写 | 快速/安全模式仍属抽样，重要场合请做完整校验 |
| ✘ 疑似扩容盘 | 发现地址回绕，或实际容量远小于标称值 | 不要存放重要数据，尽快联系商家退货 |
| ⚠ 设备异常 | 数据在某个位置后失效，可能扩容也可能是闪存故障 | 换一块 U 盘复测 |
| 检测失败 / 已取消 | 权限、占用、写保护、拔出等原因 | 按提示处理后重试 |

## 重要警告

> **快速扫描与完整校验会直接读写整块磁盘，覆盖分区表和全部数据，且无法恢复！**
>
> - 检测前请先备份 U 盘中的文件；
> - 检测完成后 U 盘会变成“未格式化/Raw”状态，**必须重新格式化**才能继续使用；
> - 不要对系统盘或唯一数据未备份的磁盘使用；
> - 安全模式虽然只写空闲区，但**扩容盘本身地址映射错乱，任何写入都可能损坏原有数据**，请先备份重要文件。

## 常见问题

**Q：为什么必须用管理员权限？**  
整盘模式需要打开 `\\.\PhysicalDriveN`、锁定/卸载卷；安全模式也需要锁定卷读取空闲位图。

**Q：提示“无法打开物理磁盘：拒绝访问/共享冲突”？**  
关闭正在使用 U 盘的程序（资源管理器窗口、杀毒扫描、下载工具），或拔插一次后重试。

**Q：安全模式提示“无法锁定卷”？**  
说明有程序正在写入该 U 盘。关闭占用程序后重试；锁定是为了保证读到的空闲位图与磁盘一致。

**Q：检测后 U 盘打不开 / 提示格式化？**  
整盘检测覆盖了分区表，属于正常现象。右键“此电脑”中的 U 盘 → 格式化，或到“磁盘管理”重新分区。

**Q：快速扫描显示正常，还要完整校验吗？**  
建议做。快速扫描是抽样检查；完整校验逐块写读比对，结论可靠得多。

**Q：安全模式能识别所有扩容盘吗？**  
不能。它只写入卷内空闲簇，不触碰 0 号扇区，**回绕型**扩容盘可能识别不出来；这类盘请用“快速扫描”。

**Q：检测很慢？**  
完整校验需要写入 + 读回两倍数据量；假盘写入速度可能很低。只想快速判断时用快速扫描或安全模式。

<details>
<summary><b>检测原理（技术细节）</b></summary>

1. **带身份的数据块**  
   每个 4 KB 测试块包含本次运行的随机 ID、逻辑偏移和校验和，数据一旦出现在别的偏移就能被识别。

2. **快速扫描**  
   全盘均匀采样 160 个点写入唯一标记，读回校验；发现异常后在“最后正常点”和“第一个异常点”之间二分写入探测标记，定位实际可写容量。

3. **完整校验**  
   先做 64 点快速预扫描（含别名探测）；正常盘继续顺序写满，每写一块立即校验末端块，发现“写入被静默丢弃”或“地址回绕”就提前终止并估算容量。

4. **安全模式（保留文件）**  
   通过 `FSCTL_GET_VOLUME_BITMAP` 读取空闲簇（exFAT 则解析其分配位图），锁定/卸载卷后只在空闲簇上抽样写入，逐点校验并二分定位；不创建/删除文件。

5. **容量估算**  
   回绕时同一数据会出现在 `偏移 + k × 真实容量`；工具对多组回绕差值取最大公约数，快速/安全模式则用二分边界定位。

6. **绕过系统缓存**  
   `FILE_FLAG_NO_BUFFERING + FILE_FLAG_WRITE_THROUGH` 直接读写，避免 Windows 缓存返回“看起来正确”的假数据。

</details>

  MainForm.cs          WinForms 界面
